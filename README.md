# Система обнаружения пневмонии по рентгеновским снимкам

## Описание проекта

Данный проект представляет собой веб-приложение для автоматического определения наличия пневмонии по рентгеновским снимкам грудной клетки с использованием методов глубокого обучения. Система предназначена для помощи медицинским работникам в процессе диагностики пневмонии.

## Технологический стек

### Backend
- Python 3.x
- Flask (веб-фреймворк)
- TensorFlow/Keras (для работы с нейронной сетью)
- SQLite (для хранения результатов)
- Docker (для контейнеризации)
- Nginx (веб-сервер)

### Frontend
- HTML/CSS
- JavaScript
- Bootstrap (для стилизации)

## Архитектура системы

### Модель машинного обучения
- Архитектура: Сверточная нейронная сеть (CNN)
- Входные данные: Рентгеновские снимки размером 224x224 пикселей в формате RGB
- Предобработка: Нормализация изображений (деление на 255.0)
- Выходные данные: Бинарная классификация (Норма/Пневмония)

### База данных
- SQLite для хранения:
  - Имени файла
  - Результата классификации
  - Уверенности модели
  - Временной метки анализа

## Функциональность

1. Загрузка рентгеновских снимков в форматах:
   - PNG
   - JPG
   - JPEG
   - Максимальный размер файла: 16MB

2. Автоматическая классификация снимков:
   - Бинарная классификация (Норма/Пневмония)
   - Оценка уверенности модели в процентах

3. Хранение и отображение истории анализов:
   - Отображение последних 3-х результатов
   - Сохранение всей истории в базе данных

## Метрики модели

Accuracy (F-1) Score    : 89.53%
Precision               : 88.37%
Recall (Pneumonia)      : 95.48% (For positive class)

## Установка и запуск

### Локальный запуск

1. Клонировать репозиторий:
```shell
git clone [URL репозитория]
```

2. Активировать виртуальное окружение:
```shell
activate-venv.bat
```

3. Установить зависимости:
```shell
pip install -r requirements.txt
```

4. Запустить приложение:
```shell
python app.py
```

### Запуск через Docker

1. Собрать Docker-образ:
```shell
docker-build.bat
```

2. Запустить контейнер:
```shell
docker-start.bat
```

3. Остановить контейнер:
```shell
docker-stop.bat
```

## Ограничения и особенности

1. Модель работает только с фронтальными рентгеновскими снимками грудной клетки
2. Рекомендуемое разрешение снимков: 224x224 пикселей
3. Время обработки одного снимка: ~2-3 секунды
